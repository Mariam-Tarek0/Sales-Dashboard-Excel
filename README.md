# Sales Dashboard (Excel)

This project presents an interactive **Excel Sales Dashboard** that analyzes sales performance using multiple data tables.  
The dashboard provides clear insights into revenue, profit, returns, and shipping costs, helping to evaluate business performance effectively.


## Objectives
- Combine multiple sales-related datasets into a single, interactive dashboard  
- Analyze sales trends and key metrics such as profit, revenue, and return rate  
- Identify top-performing regions, products, and salespeople  
- Visualize costs, performance, and return patterns for better business decisions  


## Dataset Description
The dataset contains **4 related tables**:

1. **Orders** – Includes details like Order ID, Customer Name, Product, Sales, Profit, Quantity, and Date  
2. **People** – Contains information about sales representatives and regions  
3. **Returns** – Tracks returned orders and reasons for return  
4. **Shipping Cost** – Lists shipping charges associated with each order

All tables are connected through relationships in Excel’s **Data Model**.


## Features
- Fully interactive dashboard with slicers and filters  
- Dynamic charts (sales by region, top products, profit by category, etc.)  
- KPI summary cards for Total Sales, Total Profit, Return Rate, and Shipping Cost  
- Relationships between multiple tables using Power Pivot  
- Automatic data refresh for updated reports  


## Tools & Techniques
- **Microsoft Excel**  
- **Pivot Tables & Pivot Charts**  
- **Power Pivot (Data Model & Relationships)**  
- **Slicers & Timelines**  
- **Data Cleaning & Transformation**  
- **Basic Formulas:** SUMIFS, COUNTIFS, VLOOKUP, etc.


## Results
- Comprehensive view of overall sales performance  
- Clear visualization of profit margins and return rates  
- Effective cost tracking and sales insights for each region and representative
